# Trabby Pose API Documentation

This document outlines the available REST API endpoints for the Trabby Pose backend. 

## Base URL
All API endpoints are prefixed with: `/api/`

---

## Authentication Endpoints

The API uses JSON Web Tokens (JWT) for authentication. For protected endpoints, you must include the access token in the `Authorization` header:
`Authorization: Bearer <your_access_token>`

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/auth/login/` | Authenticates a user and returns JWT access and refresh tokens. |
| `POST` | `/auth/logout/` | Logs the user out by blacklisting the current refresh token. |
| `GET`  | `/auth/user/` | Retrieves the profile information of the currently authenticated user. |
| `POST` | `/auth/token/refresh/` | Refreshes an expired access token using a valid refresh token. |

### Example: Login
**Request:**
```json
{
  "user_name": "admin",
  "password": "securepassword123"
}

```

**Response:**

```json
{
  "access": "eyJhbGci...",
  "refresh": "eyJhbGci...",
  "user": {
    "user_id": 1,
    "user_name": "admin",
    "first_name": "John",
    "last_name": "Doe",
    "email_address": "admin@example.com",
    "is_permitted": 1
  }
}

```

## Analytics: Pose Generation

These endpoints provide analytics regarding the generation of poses.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/poses/predefined/` | Returns the total number of predefined poses available. |
| `GET` | `/poses/customized/` | Returns the total number of customized poses generated by users. |
| `GET` | `/poses/totalGenerated/` | Returns the absolute total of all poses generated. |
| `GET` | `/poses/generationRate/` | Returns the rate of pose generation grouped by month. |

---

## Analytics: Pose Usage & Selection

These endpoints provide data on how frequently specific poses are selected by users.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/poses/selectionPerPose/` | Returns the selection count for each individual pose. |
| `GET` | `/poses/selectionTotal/` | Returns the aggregate total of all pose selections across the platform. |

---

## Analytics: Top Rankings

These endpoints provide ranking metrics for popular assets and configurations.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/poses/topPoses/` | Returns a ranked list of the most frequently selected poses. |
| `GET` | `/poses/topConfigurations/` | Returns the most popular JSON configurations used when generating poses. |

---

## Exports & Pose Creation

These endpoints handle the saving (exporting) of poses and retrieving export analytics.

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/exports/poses/create/` | Creates and saves a new pose configuration to the database. |
| `GET` | `/exports/total/` | Returns the total number of exported poses. |
| `GET` | `/exports/pose/` | Returns the export count grouped per pose. |
| `GET` | `/exports/month/` | Returns the volume of exports generated per month. |
| `GET` | `/exports/pose/config/` | Retrieves the specific JSON configuration values for a requested pose. |
| `GET` | `/exports/assets/mostUsed/` | Returns a ranking of the most frequently utilized individual assets inside exports. |

### Example: Create a Pose

**Request (`POST /exports/poses/create/`):**

```json
{
  "poses_fid": 1,
  "name_of_poses_generated": "Thumbs Up Pose",
  "configuration": {
    "head": "head-1.png",
    "body": "body-2.png",
    "expression": "expression-4.png",
    "limbs": "limbs-1.png"
  }
}

```

**Response:**

```json
{
  "message": "Pose successfully created",
  "pose_id": 42
}

```

## Error Responses

The API uses standard HTTP status codes to indicate the success or failure of an API request:

* **200 OK:** The request was successful.
* **201 Created:** The resource was successfully created.
* **400 Bad Request:** The request was invalid or missing required parameters.
* **401 Unauthorized:** Authentication failed or the JWT token is invalid/expired.
* **403 Forbidden:** The authenticated user does not have permission to access the resource.
* **404 Not Found:** The requested resource could not be found.
* **500 Internal Server Error:** An unexpected error occurred on the server.
